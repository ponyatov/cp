# Intro to [[concatenative programming]]
## Введение в [[конкатенативное программирование]]

1. Построение конкатенативной модели на одном из высокоуровневых языков программирования с развитым тулингом и инфраструктурой
2. Трассировка модели для выявления компонентов нижележащих слоёв
3. Трансляция графа компонентов в низкоуровневое представление на одном из массовых компилируемых языков ([[Cpp/C|C]]/[[Cpp/C++|C++]]/[[Rust/Rust|Rust]])
4. Сборка набора монолитных прошивок для [[гетерогенный кластер|гетерогенного кластера]], реализующего приложение
